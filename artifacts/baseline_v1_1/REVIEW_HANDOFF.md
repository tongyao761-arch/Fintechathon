# 十特征 baseline_v1_1 修复与验收报告

## 结论

五项问题已按约定处理。该版本可以作为后续特征实验的固定对照。十特征公式、模型参数、时间切分、训练样本和预测排名没有改变；本次不包含新特征、调参或缺失样本降排名策略。

35 项测试、依赖检查及两次串行全量运行通过。两套验证的预测 SHA-256 与旧版本一致，本地和官方评分的全部标量差异均为 0。得分的极小变化来自评分标签精度修正，不代表预测能力提升。

旧资料保留在 `artifacts/lightgbm_baseline_v1/`，不能将旧摘要与新精度摘要混用。当前完整机器结果见 `summary.json`，重复运行验收见 `acceptance.json`。

## 五项处理及影响

| 问题 | 已完成处理 | 对后续比赛研究的影响 |
|---|---|---|
| NaN 可能被当作验收成功 | 检查参与 IC 的实际标签子集；恒定预测/标签、非有限标签、不可计算 IC、非有限评分全部拒绝；一致性检查先检查有限性 | 失败实验不会带着一个看似正常的分数进入候选比较 |
| 缺失样本影响低换手 | 保留全部预测；分开保存收益和换手 Top 集合，增加缺失占比、价格有效样本换手率和月度分项诊断 | 可看清涨分来源，同时保留当前官方规则允许的排名表现 |
| 换手率错误跨过不合格日期 | 当日排除涨停后不足 100 只股票时中断持仓比较 | 在边界数据上仍与官方算法一致；当前全量分数不受此修复影响 |
| 评分标签提前压缩为 float32 | 模型训练仍使用 float32；评分使用原始标签文本解析出的 float64；双方读取完全相同的评分 CSV | 避免原始标签精度和 CSV 往返影响特征比较 |
| 重建和实验留档不完整 | 原始 CSV 可直接重建输入；保存模型、预测、明细、哈希、版本、运行状态；每次使用独立目录 | 可追溯、复现和比较实验，避免覆盖旧结果 |

本地包装器对官方脚本会产生 NaN 的输入明确报错，不把 NaN 替换成有效分数。恒定的“每日 IC 序列”本身不是错误：只要每天的 IC 可计算，其标准差为零时 ICIR 按官方约定为零。

## 数据与精度合同

- 默认数据源：`赛题五/赛题五数据/训练集.csv`，7,900,350 行、4,650 只股票、1,699 个交易日。
- 原始数据 SHA-256：`e9d23e87f7e1f9439f28f7dd951d129ea49eaacda5ad650da8576a830a6deac9`。
- 价格有效：当日 OHLC 全部有限且为正，最高价不低于其他价格，最低价不高于其他价格。训练资格：价格有效且标签非空；训练标签还必须有限且可转换为有限 float32。
- 不填补、不删行、不重新排序。完整面板在单股票内部生成历史特征后，再应用冻结训练和验证掩码。
- 输入迁移全量核验通过：主键、两类涨跌停标记、两个质量标记、全部 float32 原始特征输入、float32 训练标签和两套训练/验证掩码完全一致。clean 文件只用于此次对照，默认运行不需要它。
- 提取官方校验真值时保留原始 CSV 的数字文本，不把标签先转浮点再重新格式化。提取后按键核验，float64 数值与原始读取结果完全一致。
- 模型预测以 Parquet 保留原始 float64 数组；实际评分预测 CSV 使用 `%.17g` 输出。双方均使用官方默认 CSV 解析方式读取同一组文件。
- 本次没有更改原始或 clean CSV，也没有更改官方 `evaluate.py`、十特征文件或切分配置。

本目录提交第二次运行的摘要、来源信息、输入对照和小型诊断表；`acceptance.json` 关联两个完整运行目录。来源信息中的 Git 提交是执行时的父提交，工作区状态记录当时尚未提交的本次修复；精确执行版本以保存的源码哈希为准，不把父提交声称为修复后的版本。

## 后续使用边界

- 日常执行 `python scripts/run_lightgbm_baseline.py` 只验证 2023。显式 `--split oos_2024` 或 `--split all` 才会使用 2024。
- 该入口是冻结十特征的再现入口，始终检查旧版预测哈希。仅更换 `--experiment-id` 不会启用新特征或解除保护。
- 新特征应使用独立候选入口，固定数据、切分、训练样本和参数，复用评分、真值提取与留档模块；不能覆盖旧基线或为了通过验收而直接改写参考哈希。
- 优先用 2023 筛选，2024 用于少量候选复核。本次两年运行用于修复验收，没有依据分数调整特征或模型。
- 选择候选时同时查看官方总分、三个分项、月度结果和缺失样本诊断。缺失样本贡献是官方规则下的表现组成部分，不自动判为无效，也不能解释成可交易股票预测稳定。
- 本次没有生成最终比赛 submission，没有搜索新特征或参数，没有证明排名提升，也没有验证其他操作系统或依赖版本下预测完全相同。
