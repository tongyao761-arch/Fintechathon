# DDL②：LightGBM baseline

本次交付建立了可复现的十特征 LightGBM 对照模型，供小组后续特征和模型实验比较；它不是最终参赛模型。

## 我完成的工作

- 基于官方原始训练集的日线量价字段，构造 1/5/20 日收益、日内收益、波动率和量额比等十个只使用当日及历史信息的特征。
- 按固定时间切分训练并预测：2023 年为日常验证，2024 年为第二套验证；训练与验证之间各排除一个边界交易日。两套验证均覆盖全部 1,125,300 条记录。
- 保存模型、预测和评分明细；用未修改的官方评分脚本核对本地评分，并完成两次全量复现。

## 验证结果

| 验证期 | Rank IC | 年化超额收益 | 官方换手率 | 综合得分 |
|---|---:|---:|---:|---:|
| 2023 年 | 0.0211 | 7.06% | 48.24% | 0.1849 |
| 2024 年 | 0.0525 | 7.40% | 71.06% | 0.1300 |

两次运行的预测哈希和评分一致，本地与官方评分的全部标量差异为 0；35 项测试通过。详细结果和验收证据见 [baseline_v1_1/summary.json](baseline_v1_1/summary.json) 与 [baseline_v1_1/REVIEW_HANDOFF.md](baseline_v1_1/REVIEW_HANDOFF.md)。

## 使用与边界

在项目根目录按 [README.md](../README.md) 安装独立环境并放置官方原始训练集后，运行：

```powershell
.\.venv\Scripts\python.exe scripts/run_lightgbm_baseline.py --split all
```

原始数据、完整预测和模型文件不纳入 Git。官方换手率的 Top 组含有标签缺失记录（2023 年占 56.15%，2024 年占 27.97%），因此当前分数不能直接解释为可交易股票上的稳定表现。本次未做新特征筛选、调参或最终测试集提交。
