# 两个新模型及50/50融合固定开发预登记 v2

用户于2026-10-11明确授权实施。本版本扩展v1为六次真实fit及八个新候选；v1安装、验收、配置和原文保持原样。

机器配置为 `configs/model_comparison_v2.json`，包含继承v1的完整数据、参数、切分、对照路径和哈希。新登记及实际矩阵字节哈希在本轮 `registration.json`，第一次fit前封存。

## 固定训练与候选

- XGBoost 3.4.1、CatBoost 1.2.10各运行dev_2021、dev_2022、primary_2023；顺序先XGBoost三年再CatBoost三年。各100轮、0.05学习率、32 CPU线程、种子20260927，其余参数逐项继承v1，不搜索或早停。额外合成fit=0。
- 冻结29列P+J float32 X和原始float32 Y。只使用原训练资格且有限标签；先在完整排序历史面板构造X，再筛训练。有限值精确匹配历史缓存，NaN位置完全相同。股票、日期、标签、is_trainable及标签缺失状态不进入模型。
- 2021训练20180102—20201230、purge20201231、验证20210104—20211231，训练2,594,048行，验证1,129,950行。
- 2022训练20180102—20211230、purge20211231、验证20220104—20221230，训练3,568,878行，验证1,125,300行。
- 2023训练20180102—20221229、purge20221230、验证20230103—20231229，训练4,597,785行，验证1,125,300行。
- purge日保留X历史、排除Y，逐行下一标签市场日须早于验证起日。验证保留全部原记录，评分Y沿用原CSV精度。两模型复用同一封存矩阵。
- 基础预测XGB、CAT、LGB_XGB050、LGB_CAT050。两融合恰为0.5×对应年度封存LightGBM原预测+0.5×新模型原预测，按键及原序严格匹配，float64计算，不排名归一化、尺度校准或权重拟合。
- 每基础预测仅raw与a080两个版本，共八个。a080复用原非递归平滑，0.8×当日原值+0.2×同股票、同模型身份、精确前一市场日原值，首验证日/年度/模型边界/缺值回退当日。融合身份包含组成模型哈希及权重。不为平滑推断purge日。
- LightGBM对照仅复用各年度PJ_a100、PJ_a080的封存预测；不新增LightGBM fit/predict，不用当前最终全量模型预测历史年份。

## 比较、评分与提名

按未改动的官方evaluate.py评年度综合分，原严格wrapper及独立oracle重建逐日/月度/Top成员。默认CSV解析评分、round_trip验收封存数组、输出%.17g。保存重载、年度/逐日/月度指标及独立平滑最大绝对差≤1e-12、rtol=0。月份从年度逐日序列聚合，保留跨月换手；不逐月重置。

raw分项对PJ_a100、a080对PJ_a080，提名一律对PJ_a080，以2021—2023年度等权均分排序。融合还对组成模型同后处理版本计算分差。完整披露36个月、负差、最差年/月、IC/收益冲突、三项贡献、收益Top/换手Top/价格有效Top的缺失及无效价格构成、池比例、价格有效名单进出与Jaccard。NaN以股票日期出现次数及特征单元格为分母分别记录。附单模型raw与LightGBM raw逐日秩相关、Pearson和各Top重合率；仅诊断。

过门须均分增量严格>0.003、至少两年提升、最差年分差≥−0.005、技术/预算验收全部通过。占位否决沿用v1：至少两年无效价格换手Top出现比例高于PJ_a080，且三年平均换手贡献>0、IC+收益贡献≤0，三条件同时成立即否决。

最多一个提名。平手按1e-12固定最高锚分组，依次均分降序、最差年度分差降序、组成模型更少、raw优先、XGBoost优先、候选id字典序。没有过门者停止，不增加新参数或权重。阈值是本轮规则，不是赛题规则、显著性或未来效果保证。

## 预算与资源

fit≤6、初次predict≤6、重载predict≤6、合计predict≤12；失败入账、重试0。年度逻辑30，新24+对照6；官方/wrapper/独立各30，共实际90。月度逻辑360；wrapper和独立各聚合360，共720；官方整月独立调用0。每次函数进入前写持久事件，不能通过进程重启或新目录重置。任何真实fit/predict/评分/资源失败停止整轮，保留失败，不用部分矩阵排名。

入口prepare→train→score→audit→finalize。外部父监控含自身和全部子进程，BLAS局部限制1；串行32模型线程。启动可用内存≥14GiB、磁盘≥40GiB、逻辑CPU≥32；合计RSS≤12GiB、系统可用内存≥4GiB、运行磁盘≥20GiB、新产物≤20GiB。RSS/可用内存每0.5秒，磁盘每2秒采样；首次超限终止登记进程树。记录实际间隔，采样峰值不等于瞬时完整峰值。

每实例fit+初次/重载predict+模型保存≤1800秒，六实例累计≤10800秒；特征准备≤1800秒；score+audit累计≤7200秒；准备到最终验收墙钟≤21600秒。预算不是新模型实测或耗时承诺。所有阶段留存资源收据，独立审计与finalize包括在监控中。
