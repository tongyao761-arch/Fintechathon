# 第4步预登记

仅检查full34及lean31固定背景。2023单删24+21项，每项从原背景独立删除一个新增列。比较方向统一为删除后减删除前，同时列出相对同年十特征分差。不使用2024训练、评分或筛选；不生成比赛预测。

复用第3步三个开发切分、purge、原始数据、训练资格、模型/种子和官方评分。完整历史面板一次计算34列，再投影模型列；排名的源中间计算始终保留。十特征不删。

以下规则在第4步训练之前固定，精确可执行配置见configs/features34_step4.json。它们是保守研究约定，不是统计等效证明。

- 接近：全年删除分差绝对值≤0.001；单年明显退化：分差<−0.005。与第3步排序接近0.003独立，明显退化阈值不是允许下降额度。
- 确定删除：三个开发年份直接单删分差均≥0.001，配对块区间下界均>0，且下述分项、月度及缺失诊断护栏全部通过。
- 确定保留：三个开发年份直接单删分差均≤−0.001，配对块区间上界均<0。仅适用于被测候选背景，不外推到组合或其他背景。
- 其余归为不确定，含证据未补齐、效应接近、年份反转、区间跨零、背景结论不同。留在输入不等于证明必需。组级证据不能替代单列直接证据。
- 删除/月度护栏：每年相对原候选正分差月≥8/12，最差月≥−0.03；正月度超额收益增量最大月占比≤50%，无正增量视为收益改善未获支持。月度分数只诊断，含月首与上月末实际换手，不能替代全年评分。
- 分项及诊断护栏：每年IC差≥−0.002，年化超额差≥−0.01，官方换手增加≤0.01，价格有效换手增加≤0.01；Top缺标签/价格无效/十特征全缺失/候选全缺失占比增加各≤0.01。
- 所有对比做配对连续20交易日非循环块重采样，2000次，种子20261004，95%百分位区间；对齐候选和参照逐日IC、超额收益和官方换手日期，保留各指标有效日期。每块首日换手剔除，保留块内部原始相邻日换手，不拼接块之间持仓。区间仅解释固定预测的年度采样不确定性，不覆盖训练、模型、跨年或筛选不确定性，不作多重检验后的显著性宣称。
- 2023筛查结束后，保存拟删除与争议关键列复核清单、理由和预算，再运行2021/2022。重点覆盖A/C以及D源和F排名；2023其他列有明确负增量时也需跨年直接验证才能判为保留。最多90项补齐，未补齐只能不确定。
- 最多2个联合删除版本，每个背景最多1个，以该背景跨年确定删除列组成；如果没有满足条件的单列，可以不构造新组合，冻结原候选。联合版本必须三年完整验证；每年删除分差必须非负且所有护栏通过，否则退回原候选。联合结果不改变单列证据结论。
- 仅在明确替代/交互证据存在时考虑回补，全阶段最多2个版本，运行前记录编号、依据和预算；不是每轮2个。不为精简强行搜索。

产物为不可覆盖实验目录、运行矩阵/配置/来源快照、失败记录、原始模型及全部验证键预测、官方比较、逐日/月度/缺失诊断、配对区间、逐列背景结论、最多2个冻结候选、独立验收和证据索引。完成本步停止。
