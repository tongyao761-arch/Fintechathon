## 4. 是否保持原方案、以后是否值得优化

本次不自动替换模型或重新排列27/31列。以下结论依据实际年度/月度和分项风险，不能仅依据平均分，两种探针值不是最优值验证。

- S4R_lean31_minus4 / B1：三个开发年方向冲突，平均分差-0.000280715，最差年度2021为-0.017061041；相对原候选有14/36个负月份，最差月202106为-0.047010496。
- S4R_lean31_minus4 / B2：三个开发年均退化或持平，平均分差-0.003602230，最差年度2021为-0.006472954；相对原候选有23/36个负月份，最差月202204为-0.033561676。
- S4R_full34_minus3 / B1：三个开发年方向冲突，平均分差-0.003495918，最差年度2021为-0.017195487；相对原候选有18/36个负月份，最差月202108为-0.059191475。
- S4R_full34_minus3 / B2：三个开发年方向冲突，平均分差-0.003540164，最差年度2021为-0.012175978；相对原候选有23/36个负月份，最差月202105为-0.034708360。

四项探针的三年平均分差均为负，没有跨年一致改善；全部12项仍高于同年十特征，说明组合相对十特征的年度优势在这两种变化下保留，但相对自身冻结参数的表现并不稳定。保持原参数作为当前研究方案有依据，没有依据自动替换。叶数减少在2023有改善、在2021明显退化，说明存在模型结构敏感性；值得以后另行批准有限预算研究，但需要新的验证设计，当前证据不能确认未来优化收益。两点探针不是优化验证，不能扩大为更多参数搜索。

本次未做配对区间或显著性判断：只给固定预测的描述性年度/月度差异，不能据近零差宣布统计等价。若以后单独批准优化，须另行固定预算和新的验证设计，不能用本次测试期无标签预测分布来选模型。参数变化退化只说明对该变化敏感，改善也不证明消除了过拟合。

## 5. 无法验证的结论

测试集没有真实标签，无法验证测试期真实Rank IC、年化超额收益、完整综合分或未来表现；没有重建测试收益。预测分布和换手诊断不能证明收益有效。2021—2023已用于大量开发与选择，第4步修订具有探索性，2024此前查看且两候选2024年9月落后十特征；这些历史局限未被本次训练解除。可复现只证明实现一致，不增加新的跨期证据。整体组合有效不代表每列必需。未验证实盘费用、容量或可交易收益。
